# Sapiopedia — setup guide

Everything below takes about 45 minutes the first time. Do the steps in order.

## 1. Put the site on GitHub (10 min)

1. Create a free account at github.com if you don't have one.
2. Click **New repository** → name: `sapiopedia` → Public → **Create** (no README, no .gitignore).
3. Upload this folder. Two ways:
   - **Simplest:** on the empty repo page, click *uploading an existing file*, drag the whole content of this folder (all files and subfolders), then **Commit**.
   - **Or with git** (from this folder):
     ```
     git add .
     git commit -m "Sapiopedia: initial site"
     git branch -M main
     git remote add origin https://github.com/YOUR_USERNAME/sapiopedia.git
     git push -u origin main
     ```
4. In the repo: **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main`, folder `/ (root)` → **Save**.
   After a minute the site is live at `https://YOUR_USERNAME.github.io/sapiopedia/` (it will move to your domain in step 2).

Or, if you connect GitHub in claude.ai (Settings → Connectors), tell Claude and it will push and configure Pages for you.

## 2. Connect the domain at Namecheap (10 min, then wait up to 24 h)

**sapiopedia.com**
1. Namecheap → Domain List → *Manage* → **Advanced DNS**.
2. Delete any existing A / CNAME / URL-redirect records for `@` and `www`.
3. Add these records:

| Type | Host | Value | TTL |
|---|---|---|---|
| A | @ | 185.199.108.153 | Automatic |
| A | @ | 185.199.109.153 | Automatic |
| A | @ | 185.199.110.153 | Automatic |
| A | @ | 185.199.111.153 | Automatic |
| CNAME | www | YOUR_USERNAME.github.io. | Automatic |

4. Back in GitHub → **Settings → Pages → Custom domain**: type `sapiopedia.com` → Save. The file `CNAME` in this repo already contains the domain.
5. Once the DNS check passes (minutes to a few hours), tick **Enforce HTTPS**.

**sapiopedia.org** (redirect to .com)
1. Namecheap → Domain List → *Manage* → **Redirect Domain** (or Advanced DNS → *URL Redirect Record*).
2. Source `@` → Destination `https://sapiopedia.com` → type **Permanent (301)**. Add the same for `www`.

## 3. Analytics and Search Console (10 min)

1. **Analytics:** create a free account at plausible.io (paid after trial) or analytics.google.com (free).
   Copy the snippet they give you into `build.py`, variable `ANALYTICS`, then run `python3 build.py` and push.
2. **Google Search Console:** search.google.com/search-console → *Add property* → **Domain** → `sapiopedia.com`.
   Google gives you a TXT record: add it in Namecheap → Advanced DNS (Type TXT, Host @). Click *Verify*.
3. In Search Console → **Sitemaps** → submit `https://sapiopedia.com/sitemap.xml`.
4. Do the same in **Bing Webmaster Tools** (it can import from Search Console in one click).

## 4. Reserve the handles (5 min)

Create accounts named **sapiopedia** on TikTok, Instagram, Pinterest and YouTube, even if you don't post yet.
Pinterest: convert to a *business* account and claim your website (Settings → Claimed accounts) once the domain works.

## 5. Ads (later, once you have ~20 real pages)

1. adsense.google.com → add site `sapiopedia.com` → copy the `<script>` snippet into `build.py`, variable `ADSENSE`.
2. Rebuild, push, request review. The `<div class="ad">` placeholders in each page are where you put ad units (or turn on *Auto ads*).
3. Add a cookie-consent banner before ads go live for EU visitors (AdSense offers one under *Privacy & messaging*).

## How to add a page

Every page is generated by `build.py` from a small Python function (see `tool_flour()` and `quiz_colour()` as models).
Add a new function with the EN and FR versions, call it in the list, run `python3 build.py`, commit, push. The sitemap updates itself.

## Files

- `build.py` — generates every HTML page and the sitemap
- `assets/style.css`, `assets/common.js` — shared look and helpers (share button, result card image)
- `en/`, `fr/` — generated pages, one folder per page
- `CNAME`, `robots.txt`, `sitemap.xml`, `404.html`, `index.html` (language chooser)
