Questions

What is a good middle name for Immanuel?

Names with a different number of syllables flow best with Immanuel, for example Michel, David, Joseph.

What sibling names go with Immanuel?

For a sister, Maria or Josette; for a brother, Aaron or Michael: the same style, but a different first letter and ending.

Does Immanuel work as a middle name?

Yes. With 3 syllables, Immanuel sits best after a first name with 2 syllables.
